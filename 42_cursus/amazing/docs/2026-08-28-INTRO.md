Areas to solve:

-------------------------------------------------------------

1. Reading the configuration values

   Read the input given to the program. The subject specifies that the
   program is called as follows

   python3 a_maze_ing.py config.txt

   The goal is to take the first argument, open the file, read its
   contents, and pull out the values for the following parameters

   - WIDTH : int
   - HEIGHT : int
   - ENTRY : (int, int)
   - EXIT : (int, int)
   - OUTPUT_FILE : str
   - PERFECT : bool

   To do this we can write a MazeConfig class as follows:

   - Pass the constructor the path of the file to read the config
     values from

   - During construction, open the file and read the values

   - Expose the values that were read through methods

     WIDTH -> getWidth()
     HEIGHT -> getHeight()
     ENTRY -> getEntry()

   Usage:

    mazeConfig = MazeConfig("./config.txt")

    print(mazeConfig.getWidth())
    print(mazeConfig.getHeight())
    startingPoint = mazeConfig.getStart()

 2. Class for working with the maze

    Define the main Maze class that will be used to generate the
    maze. This class must let the user do the following things:

    0. Build a maze of given dimensions

       maze = Maze(width, height)

    1. Get the dimensions (WIDTH x HEIGHT)

       width, height = maze.getDim()

    2. Given a point and a direction, say whether a wall exists

       wall = maze.getWall(x, y, direction)

    3. Given a point, say whether that point is closed in by four walls

       isClosed = maze.noAcess(x, y)

    4. Given a point, build a wall in a direction in such a way as to
       keep the maze coherent in the adjacent points

       maze.buildWall(x, y, direction)

    5. Given a point, destroy a wall in a direction in such a way as to
       keep the maze coherent in the adjacent points

       maze.destroyWall(x, y, direction)

    6. Return a list of reachable neighbour points

       maze.neighboursPoints(x, y)
